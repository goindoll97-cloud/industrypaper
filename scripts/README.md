# 2026-5호 LLM 실행 및 채점 코드

이 폴더는 **현재 2026-5호 별표를 대상으로 CAS·함량·유해성 분류를 판정하는 LLM 실험 코드**를 둘 곳입니다.

`../llm_capability_study/`는 현재 논문 연구를 진행하며 29개 규제항목 검증셋을 수집·감사하던 작업 폴더입니다.
기존 스크립트는 고시 전체 1,354개 대상과 가상 함량 판정을 처리하도록 작성된 것이 아니므로 **그대로 돌리지 않습니다**.
새 검증셋 엑셀과 Gold 스키마를 확인한 뒤, 별도 LLM 실행 및 채점 스크립트를 추가합니다.

기존 Claude/Hybrid 실험의 실행 코드는 `../archive/previous_claude_experiment/`에 보관합니다.
