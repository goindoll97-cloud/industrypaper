# 현재 연구 폴더 안내 (2026-11-18)

이 폴더는 **현재 논문 연구를 진행하며 확보한 검증셋 수집·법적 범위 대조·표본 편향 분석·품질관리 자료**입니다.
이전 폴더 정리 작업에서 Claude 보관소로 이동됐지만, 이는 분류 오류여서 저장소 최상위로 복원했습니다.

## 중요한 구분

- 현재 연구의 **최신 실험 질문:** 2026-5호 전체 별표를 이용하여 CAS/물질 식별, 유해성 유형, 가상 함량기준 적용을 LLM에 평가.
- 이 폴더 안의 **기존 `build_validation_dataset.py` 및 `validation_dataset/v1/`**: 이전 연구설계 단계의 29개 규제항목 카탈로그 기반 평가 초안. **2026-5호 함량검증셋과 동일한 Gold가 아닙니다.**
- 기존 `audit_sampling_design.py`, `candidates/`, `tests/`: 신규 연구에서 필요한 후보 품질관리·분류편향 검토 아이디어의 기반자료로 활용 가능.
- 구 Claude/Hybrid/Ollama 성능 실험의 실제 실행 파일과 응답 결과: **`../archive/previous_claude_experiment/`**에만 보관.
