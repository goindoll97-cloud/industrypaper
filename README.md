## 현재 실험

- **근거자료:** 화학물질안전원고시 제2026-5호 「인체급성유해성물질, 인체만성유해성물질 및 생태유해성물질의 지정고시」 별표
- **평가 내용:** CAS 식별, 고시 지정번호, 인체급성·인체만성·생태유해성 분류 및 가상 함량에 따른 해당 여부
- **데이터셋 설계:** 물질 300종 × 가상 함량 4개 = 질문 1,200건
- **평가 입력과 정답지는 분리.** LLM 프롬프트에 정답지와 후보별 고시 판정 결과를 제공하면 안 됩니다.
- **범위 주의:** 여기서 판정하는 것은 지정고시상 유해성물질 해당 여부입니다. 실제 제조·수입·취급 행위의 법 위반 여부를 직접 판정하지 않습니다.
