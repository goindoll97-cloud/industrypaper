# 2026-5호 LLM 벤치마크 — 현재 연구

**실험에 사용할 파일은 두 개입니다.**

1. [검증셋](validation_2026_5/2026_5_LLM_Validation_Set.xlsx) — LLM에 제공할 `TEST_CASES` 1,600건 및 `LEGAL_REFERENCE` 1,451행(공식 별표 전체)
2. [Gold 정답지](validation_2026_5/2026_5_LLM_GOLD_Answer_Key.xlsx) — **LLM에 제공하지 않음**; 채점에만 사용

## 실험 설계

- 등재물질 **300종** × 4개 가상 함량: **1,200건**.
- 미등재 CAS 후보 **100종** × 가상 함량 0.1%, 1%, 5%, 25%: **400건**.
- 총 **400종, 1,600건**. 서로 다른 CAS는 400개이며 각 CAS마다 질문 4개.
- 함량에 따른 유해성 해당 600건, 비해당 1,000건.
- `listed_in_annex` True 1,200건, False 400건.
- 고정 시드 `20261118`로 전체를 섞어 시험 ID `Q-00001`~`Q-01600`을 재할당했습니다. **예전 ID와 직접 대응하지 않습니다.**

### 판정 대상과 한계

이 벤치마크에서 `listed_in_annex`는 **2026-5호 별표 `cas_raw`에 입력 CAS가 명시적으로 존재하는지**를 뜻합니다. 한 셀에 여러 CAS가 적힌 경우 각 번호를 분리해 대조합니다.

**중요:** CAS 번호가 별표에 직접 없다는 사실이 그 물질이 법적으로 완전히 비규제라는 뜻은 아닙니다. 포괄 물질군, 염류, 구조 범위, 예외 조항에 관한 법적 판단은 이 벤치마크에서 다루지 않습니다. 따라서 신규 100종의 False를 법률상 `비규제대상` 확정으로 해석해서는 안 됩니다.

## 실행 전 확인 사항

- 평가 모델에는 **검증셋의 `TEST_CASES` 프롬프트와 `LEGAL_REFERENCE`만** 제공하고 Gold는 노출하지 마세요.
- 현재 GitHub 저장소는 공개이므로, **정답지 파일이 저장소에 포함되어 있다는 사실 자체가 모델 오염 및 평가 누출 위험**입니다. 엄격한 블라인드 평가에는 비공개 Gold 보관을 권장합니다.
- 모델마다 같은 별표, 질문, 온도, 응답 형식을 사용하세요.
- 동일 CAS의 4개 함량 질문은 통계분석 시 독립 물질 4종으로 계산하지 마세요.
- `reason_ko`는 의미적으로 평가하세요. JSON 문자열의 문장까지 정확히 일치하는지 채점해서는 안 됩니다.

예전 29개 규제대상 설계 및 Claude/Hybrid 실험 자료는 `archive/`에 보관되어 이번 연구에서 사용하지 않습니다.

자세한 SHA-256 및 파일명은 [DATA_FILES_MANIFEST.json](DATA_FILES_MANIFEST.json)에 있습니다.
