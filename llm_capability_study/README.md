# 연구 방향: LLM 성능 향상과 화학물질 규제대상 식별의 정확성·일관성

> 상태: 연구 설계 및 검증물질 확장 진행 중 (2026-11-17 기준)  
> 연구 유형: **LLM 단독 평가 및 성능 수준별·반복별 비교**  
> 기존 연구와의 관계: 기존 Claude/Hybrid 실험 자료는 보존하되, **이번 연구의 주효과 분석에서 Hybrid는 제외**한다.

## 1. 연구의 출발점

현행 화학물질 규제정보에는 CAS 번호로 직접 특정된 물질 외에도 원물질과 염류, 화학물질군, 이성질체 및 혼합물과 같이 포괄적으로 정의된 규제항목이 존재한다. 따라서 개별 화학물질의 CAS·분자구조가 주어졌을 때 그 물질이 어느 규제항목에 속하는지를 정확히 식별하기 어려울 수 있다.

LLM의 일반적인 성능과 화학 관련 추론 능력은 계속 발전하고 있다. 그러나 **모델이 고도화되면 이러한 규제대상 식별의 어려움이 실제로 줄어드는지**, 그리고 **같은 물질에 대해 판정이 반복적으로 안정적인지**는 별도로 검증해야 한다.

본 연구는 **LLM의 성능 수준 차이가 화학물질 규제대상 식별의 정확도, 반복 일관성 및 오류 양상에 미치는 영향을 실증적으로 평가**한다. 성능이 높은 모델에서조차 지속되는 오류 유형을 확인해 LLM을 규제정보 분석에 활용할 수 있는 범위와 한계를 제시한다.

**개념적 범위에 관한 주의:** 본 연구가 다루는 것은 *이미 정해진 규제목록 안에서 대상 물질을 식별하는 어려움*이다. 법령 자체에 규제 조항이 없거나 법적으로 적용범위가 정해지지 않은 문제까지 LLM이 해결하는지 검증하는 것은 아니다. LLM의 답변은 법적 판단을 대체하지 않는다.

## 2. 연구 질문 및 검증 가설

| 연구 질문 | 검증 내용 | 사전에 예상되는 방향(가설) |
| --- | --- | --- |
| **RQ1. 성능 수준이 다른 LLM 사이에 규제대상 식별 정확도 차이가 있는가?** | 동일한 규제목록, 동일 물질, 동일 평가조건에서 모델 간 정확도 비교 | **H1:** 일반적 능력이 높은 모델이 평균적으로 더 높은 정확도를 보일 가능성 |
| **RQ2. LLM 성능이 높을수록 반복 판정 일관성이 향상되는가?** | 각 물질을 모델별로 여러 번 독립 평가하여 판정 변동 확인 | **H2:** 모델 수준에 따라 판정 안정성에도 차이가 있을 가능성 |
| **RQ3. 모델 수준이 높아져도 남는 오류는 무엇인가?** | 규제대상 누락, 비대상 물질의 잘못된 포함, 규제항목 오지정, 염류·화학물질군·혼합물별 오류 비교 | **H3:** 일부 화학적·규제적 경계 사례에서 체계적 오류가 지속될 가능성 |

가설은 결과를 미리 정해둔 결론이 아니다. 정확도 향상에도 불구하고 일관성 개선이 없거나, 특정 유형에서 개선이 없는 결과도 연구 질문에 대한 중요한 답이 된다.

## 3. 무엇을 비교하지 않는가?

- 이번 연구의 **중심 비교는 LLM 단독 모델 간 차이**이다.
- 규칙 기반 분자구조 판정(RDKit), deterministic gate, Hybrid의 이점은 이번 논문의 주요 연구 질문과 분리한다.
- 기존 `ollama_followup/`의 Hybrid 실험은 보존하지만, 이번 연구의 모델 간 비교 표·통계에 섞지 않는다.
- 모델 파라미터 수만으로 '좋은 모델'을 단정하지 않는다. **외부 벤치마크·출시 세대·모델 규모**와 **본 연구 내 실제 성능**을 구분하여 기술한다.
- 특정 모델에서 정확도가 높았다는 사실만으로 *향후 모든 LLM이 해결할 것*이라는 인과적 결론은 내리지 않는다.

## 4. 고정 평가 범위: 29개 규제항목

현재 저장소의 `data/regulatory_catalog.csv`에는 **29개의 규제대상 ID**가 동결되어 있다. 실험의 첫 단계에서는 모든 LLM이 **같은 29개 규제항목**을 검색하도록 한다.

모델은 검증 대상 물질의 CAS 입력, 사전 확인한 SMILES(있는 경우) 및 동일하게 제공된 규제목록을 근거로 결과를 출력한다.

- `FOUND`: 해당 물질이 29개 항목 중 특정 `target_id`에 속한다고 판단
- `NOT_FOUND`: **이번에 고정한 29개 규제항목에 해당하지 않음**. 국내 전체 법령에서 비규제라는 뜻이 아님
- `REVIEW`: 제공된 정보로 안정적으로 판정하기 어려워 판단을 유보

평가 시에는 정확한 `target_id` 선택 여부를 별도로 검증한다. 단순히 FOUND 여부만 맞히더라도 잘못된 항목을 선택하면 정답으로 처리하지 않는다. 여러 규제항목에 중첩될 수 있는 사례 및 법적 범위가 불명확한 사례는 Gold 확정 전에 별도 규칙이 필요하다.

규제목록 자체를 확대하는 경우에는 기존 29개 목록 실험과 **분리된 별도의 실험 조건**으로 관리한다.

## 5. 검증물질: 기존 자료와 확대 자료를 구분

### 5.1 기존 동결 자료

- 질의 수: **112건** (대상 FOUND **60건**, 비대상 NOT_FOUND **52건**; 29개 목록 내 판정)
- 유형별: **원물질·염류 72건, 화학물질군 30건, 혼합물 10건**
- 입력 자료: `data/retrieval_INPUT.csv`
- Gold: `data/retrieval_GOLD.csv`
- 기존 Claude 결과는 **이 112건에서의 역사적 비교 결과**로만 활용한다. 새로운 확장자료에 대한 Claude 결과나 Claude 반복실험이 이미 존재한다고 주장하지 않는다.

### 5.2 신규 PubChem 후보 (2026-11-17 수집 결과)

실제 온라인 수집으로 **신규 후보 87건**이 확보되었다.

| 수집 경로(candidate_stratum) | 건수 | 의미 |
| --- | ---: | --- |
| `CATALOG_LISTED` | 20 | 규제목록 직접 등재 CAS에서 파생된 후보 |
| `NEAR_CATALOG` | 27 | 규제목록 주변 염류·구조 유사성 후보 |
| `INDEPENDENT_GENERAL` | 40 | 규제항목을 출발점으로 사용하지 않은 일반 화학물질 탐색 후보 |
| **합계** | **87** | **전부 REVIEW_PENDING, 법적 정답 미확정** |

독립적인 일반 화학물질은 24건(다양한 화학물질명 탐색)과 16건(CID 탐색)으로 확보되었다. 온라인 수집 당시 신규 PubChem API 요청 한도 350회에 도달했으므로 목표 100건을 모두 채우지는 못했다. 혼합물은 **신규 0건**으로 별도의 보강이 필요하다.

따라서 **112 + 87 = 199건은 현재 확보한 사례/후보의 합계이지, 정답이 검증된 199건이 아니다.**

### 5.3 검증자료 확대 원칙

- **잠정 목표: 전체 300~400개의 고유 검증 사례**. 표본 수는 정답 검증률, 유형별 사례 수, 예상 효과 크기와 통계적 정밀도를 검토한 뒤 확정한다.
- 규제목록과 직접 관련된 물질만 수집해서는 안 된다. **규제대상, 규제범위 경계 사례, 구조 유사물질, 규제목록과 독립적으로 선정한 일반 화학물질**을 포함한다.
- 주요 모집 경로는 직접 등재, 근접 물질, 독립 일반 물질의 **20:40:40 잠정 모집 비율**이다. 이 비율은 **법적 FOUND/NOT_FOUND 비율이 아니다**.
- 혼합물, 유사하지만 비대상인 물질 등 부족한 유형을 의도적으로 보강한다. 실재가 확인되지 않은 혼합물을 임의 조합해 만들지 않는다.
- PubChem의 CID 무작위 숫자 탐색은 재현 가능한 *후보 탐색법*일 뿐 화학물질 전체의 균등 무작위 대표표본이 아니다.
- 후보 CAS/SMILES 중복, 원물질·염류, 입체화학, 물질군 중첩 여부를 별도 검토한다.
- 샘플링 편향 때문에 실험 전체 정확도를 실제 화학물질 모집단에서의 발생 비율로 일반화하지 않는다.

## 6. 정답(Gold) 확정 및 평가정보 누출 방지

1. 신규 PubChem 수집 결과는 **후보**이다. 모든 신규 행은 `REVIEW_PENDING`으로 시작한다.
2. 물질 정체는 PubChem CAS/CID/SMILES와 가능한 독립적인 화학물질 근거자료로 점검하고, 규제대상 여부는 **적용 법령/고시의 해당 개정판과 정확한 규제범위**를 대조한다.
3. 가능하면 서로 독립된 두 명이 최종 `target_id` 또는 `NOT_FOUND`를 확인하고 불일치는 조정한다. 해결되지 않는 사례는 보류하거나 사전 지정된 별도 분석으로 구분한다.
4. Gold는 **모델 예측을 보기 전에** 확정·버전관리·해시 기록한다. 모델이 틀렸다는 이유로 정답을 뒤늦게 바꾸지 않는다.
5. 평가 입력에는 **CAS, 검증된 SMILES, 동결된 규제목록**만 포함한다. 화학물질명, 수집 경로, 사람의 규제대상 힌트, Gold, 판정 검토 기록을 LLM에 제공하지 않는다.
6. 독립 일반 물질로 수집되었다는 이유만으로 `NOT_FOUND`를 자동으로 부여하지 않는다.

## 7. 모델 비교 및 반복평가

모델 구성은 최종 확정 전이며, **서로 다른 능력 수준의 소형·중형·대형 LLM**과 가능하다면 다른 계열 모델을 포함하는 방향으로 설계한다.

- 동일 규제목록/질의/입력정보를 사용하고 동일한 프롬프트를 유지한다.
- 모델 이름과 정확한 버전/해시 또는 digest, 양자화 방식, 생성 파라미터(temperature 등), 문맥 길이, 실행 일시, 하드웨어를 저장한다.
- 모든 모델에 긴 규제목록이 입력될 수 있는지 **실제 컨텍스트 여유와 입력 절단 여부**를 먼저 확인한다.
- 물질별 **최소 5회 반복**을 기본으로 하며, 필요 시 10회로 확대한다. 동일 모델이 동일 답을 반복하는 일관성과 정답 여부를 분리하여 평가한다.
- 각 반복 호출의 원본 응답, 파싱 성공/실패, 판단 유보, 오류를 개별 보관한다.
- 5번 반복한 400건은 독립적인 2,000개 물질이 아니다. 통계적 불확실성을 계산할 때 **물질 단위의 반복 측정 구조**를 반영한다.

## 8. 주요 평가 지표 및 결과물

| 평가축 | 주요 지표 | 해석 질문 |
| --- | --- | --- |
| 정확성 | 정확한 target ID 일치율, FOUND 재현율, NOT_FOUND 특이도 | 더 높은 수준의 모델이 더 정확한가? |
| 오류 유형 | 위음성, 위양성, 다른 항목 오지정, REVIEW/무응답 | 어떤 오류가 어디에 집중되는가? |
| 반복 일관성 | 물질별 5회 출력 일치율, 최빈판정 비율, 전체 정확도의 반복 간 변동 | 같은 물질을 다시 평가해도 같은 판단인가? |
| 유형별 차이 | 염류·화학물질군·혼합물·독립 일반 후보별 정확도 | 향상되는 유형과 남는 한계는 무엇인가? |
| 통계 비교 | 물질 단위 쌍체 비교, 사례 단위 부트스트랩 등 | 모델 차이가 표본의 우연한 변동을 넘어서는가? |

정확하지만 일관성이 낮은 모델, 일관되지만 지속적으로 틀리는 모델을 명확히 구분한다. 최종 결론은 실험결과에 따라 결정하며 특정 방향의 개선을 전제하지 않는다.

## 11. 논문의 최종 메시지(예정)

> **LLM의 성능 향상이 규제대상 식별의 정확성 및 반복 일관성을 어디까지 높이는지, 그리고 성능이 높은 모델에서도 어떤 화학적·규제적 경계 사례가 오류로 남는지를 검증한다.**

이 결론은 모델과 법규를 대체할 수 있다는 선험적 주장이 아니라, 정답 기반 비교평가 결과로 뒷받침되어야 한다.
