# 현재 논문: 2026-5호 고시 기반 LLM 규제대상·함량 판정

**이곳은 현행 논문 실험의 작업 폴더입니다.** 이전 29개 항목용 수집/검증 코드는 모두 `archive/previous_29_target_dataset_design/`으로 이동했으며, Claude/Hybrid 실험은 별도의 보관 폴더에 남겨 두었습니다.

## 어디에서 무엇을 찾나요?

| 경로 | 용도 |
| --- | --- |
| `data/2026_5_LLM_Validation_Set.xlsx` | LLM에 제공할 평가 질문 1,200건 (300종 × 가상 함량 4개) |
| `data/2026_5_LLM_GOLD_Answer_Key.xlsx` | 정답지: 모델에 절대 노출하지 않고 채점 단계에서만 사용 |

## 이번 실험의 평가내용

- **공식 근거:** 화학물질안전원고시 제2026-5호, 인체급성유해성물질·인체만성유해성물질·생태유해성물질 지정 목록.
- **LLM 질문:** 특정 CAS 번호의 물질을 가상 제품/혼합물에 정해진 중량%로 포함한다고 가정했을 때, 해당 고시의 지정번호·유해성 종류·함량기준 적용 여부를 판정.
- **Gold:** 고시 원본의 범위·유형별 함량기준에 근거하여 모델 답변과 별도로 산정. 정답 파일은 평가 모델에게 노출 금지.
- **주의:** 지정고시상 해당 여부와 실제 법규 위반 여부는 서로 다릅니다.

## 검증셋의 현 단계 한계

- 원본 별표 중 CAS 및 함량 기준이 명확한 **300종**을 활용한 첫 버전입니다.
- 같은 화학물질을 여러 함량으로 평가하므로 질의 1,200개가 독립 화학물질 1,200종을 뜻하지 않습니다.
- CAS가 없는 포괄 물질군, 예외 조항이 복잡한 사례, 목록 바깥 물질의 오탐 평가는 현재 버전에서 제한적입니다.
- 모델 간 정확도 비교를 위해 동일한 별표 판본, 동일한 프롬프트 규칙과 조건을 고정해야 합니다.
- 기존 Claude 응답/점수 및 29개 항목용 Gold는 이번 평가에 포함하지 않습니다.
