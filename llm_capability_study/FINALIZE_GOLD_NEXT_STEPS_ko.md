## 4. 모델 비교실험 설계 (Gold 동결 후에만 수행)

- **모델 입력:** `validation_INPUT.csv`의 query_id, CAS 및 해당하는 경우 SMILES만 모델에 제공. 후보명·출처·GOLD·유형·검토기록은 절대 모델 입력에 제공하지 않음. 29개 고정 규제 참조자료·프롬프트는 모든 모델에 동일하게 제공.
- **주요 평가단위:** 독립 화학물질 질의(query_id). 동일 질의 반복응답은 독립 표본이 아님.
- **실험:** 모델별 각 질의 **5회 독립 응답**, 동일한 해독 설정·컨텍스트·규제 참조판, 모델명·모델 버전·정량화·실행일 기록.
- **주요 지표:** 정확한 규제항목 집합 일치(Exact target-set match), FOUND 민감도, NOT_FOUND 특이도, Balanced Accuracy. `REVIEW`(판정 보류)의 비율과 정확도 처리 규칙을 별도 사전등록.
- **보조 지표:** 오탐·미탐·오분류, 다중항목 완전 일치, 모델별 5회 응답 일관성, 29개 항목별 검출 가능 범위, 유형 및 난이도 층화 결과.
- **표본 편향 조치:** 신규 확장 193건과 역사적 112건을 별도 보고. 전체 통합 305건 결과는 보조자료. `GENERAL_CHEMICAL` 및 `BOUNDARY_CANDIDATE`를 고유한 화학 종류인 것처럼 해석하지 않음.
- **혼합물:** 6건의 합성 2성분 도전과제는 실제 혼합물 성능에서 분리해 보고.
- **미측정 대상:** 양성 0건인 6개 target에 대해 '모델이 식별할 수 있다/없다'를 주장하지 않음.
- **통계:** 모델 간 동일 query_id를 사용한 쌍체 비교, 질의 단위 cluster bootstrap 및 다중 비교 관리. 5회 반복을 표본 수 5배로 취급하지 않음.
- **오염 예방:** 기존 Claude 112건 결과는 역사적 비교용으로만 해석. 새로운 193건의 Gold를 모델 응답을 보고 수정하거나 프롬프트를 평가셋에 맞게 최적화하지 않음.

## 5. 사용자에게 필요한 작업

- **우선 제공:** PS:: 9개 범주와 규제혼합물 6개에 대한 원자료(고시·목록 엑셀·PDF·공식 링크). 확보할 수 없다면 **해당 범위를 법정 규제 식별 실험의 대상으로 유지할 것인지** 연구 범위를 먼저 결정.
- **독립 판정:** 화학물질 규제범위 해석이 가능한 검토자 2명의 참여 및 증빙 문서 기록. 두 검토자가 각자 서명한 검토 CSV를 GitHub PR에 올리거나 이 대화에 첨부. 불일치한 행은 전문가 조정.
- **SMILES 원자료 확인:** baseline RQ-0003 / RQ-0096의 SMILES 누락을 보완할지, 전체 질의를 CAS-only로 통일할지 결정.
- **실험 환경 정보:** Gold 확정 이후 모델 목록(API/로컬 모델)과 실험에 사용 가능한 GPU/비용을 알려주면 비교실험 실행 코드를 최종 모델 사양에 맞춰 구성.

**현재 로컬 Python 실행은 필요하지 않습니다.** GitHub Actions에서 `audit_gold_readiness.py`, `audit_sampling_design.py`, RDKit 검증, 단위시험 및 초안 생성이 실행됩니다.
