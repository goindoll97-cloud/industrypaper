# LLM 성능 수준에 따른 화학물질 규제대상 식별 연구

## 지금 무엇부터 해야 하나?

**1순위는 새 물질의 정답 선정 기준을 고정하는 것**입니다. 규제목록 29개 항목을 그대로 두고, 이 목록 안에서의 해당/비해당 여부를 평가합니다. **NOT_FOUND는 법령상 규제되지 않는다는 뜻이 아니라 이번 29개 목록에서 해당 항목을 찾지 못했다는 뜻입니다.**

기존 Claude의 112건 데이터는 절대 수정하지 않습니다. 해당 자료는 이전 Claude 결과와 직접 비교하는 공통 기준자료입니다. 신규로 추가하는 물질은 별도 확장 검증자료로 관리합니다.

## 기존 자료 점검

GitHub 자동점검에서 아래를 검증합니다.

- 기존 입력 112건, 규제항목 29개, 정답 112건
- 해당 60건, 비해당 52건
- 원물질/염류 72건(해당 36, 비해당 36)
- 화학물질군 30건(해당 15, 비해당 15)
- 혼합물 10건(해당 9, 비해당 1)
- 수작업 검토 대상으로 표시된 비해당 52건의 연구자 승인 기록
- PubChem SMILES 누락 상태(현재 기존 질의 중 5건에서 하나 이상의 CAS 구조 누락)

아래 명령으로 동일한 점검 보고서를 만들 수 있습니다.

    python llm_capability_study/audit_baseline.py

보고서가 저장되는 위치:

- llm_capability_study/output/baseline_summary.json
- llm_capability_study/output/baseline_inventory.csv

이 명령은 물질을 생성하거나 API를 부르지 않습니다.

## 검증물질 확대: 첫 목표는 신규 40~60건

한 번에 총 400건을 목표로 수집하지 말고, **법적 근거를 정확하게 검토할 수 있는 신규 40~60건**부터 시작하는 것을 권장합니다.

가장 먼저 혼합물 유형을 보강합니다. 특히 기존 혼합물에는 비해당 사례가 단 1건이므로, 비슷한 구성성분을 가지지만 29개 목록의 규제혼합물과 동일하지 않은 물질/혼합물 사례를 검토해야 합니다.

초기 수집 가이드(정답을 확정하기 전의 모집 목표):

| 유형 | 신규 시범 수집 목표 | 강조할 요소 |
| --- | ---: | --- |
| 원물질·염류 | 15~20건 | 명백한 염류와 구조가 비슷하지만 다른 물질 |
| 화학물질군 | 15~20건 | 규제물질군 해당/비해당, 원소 산화수 및 구조 유사성 |
| 혼합물 | 15~20건 | 구성성분의 정확한 일치와 근접한 비일치 |
| **총계** | **45~60건** | 비해당·어려운 사례를 의도적으로 확보 |

※ 실제 사례 확보 난이도에 따라 조정합니다. 현행 목록과 법령상 모호한 사례는 정답을 임의로 확정하지 않습니다.

## 새 물질 1건을 입력하는 방법

`new_cases_template.csv`를 복사한 뒤, 한 줄에 물질 1건씩 추가합니다.

1. CAS 또는 혼합물 구성성분 CAS(`|`로 구분), 유형, 난이도 태그를 기재합니다.
2. 대상 법령/고시의 **특정 개정판과 출처 URL, 확인일**을 적습니다.
3. 법령상의 규제범위에 비추어 29개 대상 중 하나에 포함되는지 판단합니다.
4. CAS 및 구조의 동일성을 확인할 수 있는 신뢰할 만한 출처를 남깁니다. PubChem에서 SMILES가 없으면 빈칸으로 유지하고 검토합니다.
5. 서로 독립된 2인의 검토(가능한 경우)를 받은 뒤 의견이 다르면 조정합니다.
6. 확인하지 못한 사례는 `REVIEW_PENDING`으로 유지합니다. **이 상태는 모델 정확도 평가에 사용하지 않습니다.**

모델에 제공할 수 있는 정보는 검증물질의 CAS 및 확인된 SMILES와 고정된 29개 규제목록뿐입니다. **이름, 정답, 검토 근거, 검토자의 판단은 모델에 입력하면 안 됩니다.**

## 그 다음에 모델 실험

신규 자료의 정답 검토가 완료되면 버전과 SHA256을 기록하고 데이터셋을 동결합니다. 이후 Hybrid를 사용하지 않고 LLM 단독 평가만 수행합니다.

- 모델별 똑같은 입력자료, 똑같은 규제목록, 가능한 한 동일한 질문
- 모델별 5회 반복 평가
- 정확도, 규제대상 재현율, 비대상 특이도, 잘못된 규제대상 포함·누락, 반복 판정 일치율
- 기존 Claude는 기존 112건에서만 별도로 제시하며, Claude를 반복 검증했다고 표현하지 않습니다.
- 신규 확장자료에서는 반복 평가가 가능한 로컬 LLM끼리 비교합니다.

연구질문, 정답 판정 기준, 모델 선정·분석 기준의 자세한 내용은 [PROTOCOL.md](PROTOCOL.md)를 참고하세요.

> 기존 `ollama_followup`은 이전 Hybrid 비교 연구용 코드입니다. 새로운 LLM 성능 비교 연구의 실행 결과에 섞지 않습니다.
