## 추가 분석: 혼합물 30문항의 함량기준 적용 및 사후 통합(S7–S9)

기존 B90 실험은 원물질 및 염류, 화합물군, 혼합물 각 30문항의 **고시 지정범위 판단**을 평가했습니다. 혼합물 입력에는 구성성분별 질량백분율이 포함되어 있었지만, 그 함량이 유해성별 고시 기준을 만족하는지를 점수화하지 않았습니다.

- **추가 실험:** 기존 B90과 동일한 혼합물 30문항(쉬운 문항 15개/2개 성분, 어려운 문항 15개/3개 성분; 총 75개 성분)에서 인체급성·인체만성·생태유해성 함량기준 충족 여부를 평가했습니다. 3개 모델(Qwen3 4B Instruct, Qwen3.5 4B, Qwen3.5 9B) × 5회 = 450건입니다. 기존 Qwen2.5 3B는 추가 실험을 하지 않았으므로 사후 통합표에서 제외합니다.
- **연결 단위:** 동일한 `model`, `test_id`, `repeat`에 해당하는 기존 실험과 추가 실험의 응답을 연결했습니다. **2단계가 1단계의 실제 출력을 입력받은 연속형 실험은 아닙니다.** 결합 정확도는 서로 독립적으로 실행한 두 실험의 *사후 분석*입니다.
- **핵심 지표:** 기존 지정범위 및 고시 제3조 관련 판단 정확도(`old_scored_scope_plus_article3_correct`), 추가 함량기준 전체 정확도(`new_thresholds_all_correct`), 두 조건 모두 정답(`joint_old_scored_scope_new_threshold_correct`), 기존 엄격채점과 새 함량기준 모두 정답(`joint_old_scored_strict_new_threshold_correct`)을 구분합니다. S7은 5회 반복별 정답률의 평균이며, 표의 정답 건수는 대표 1회차 30문항 기준입니다.
- **사후 결합 최종판정:** 기존 실험의 `all_components_designated` 또는 기존 실험에서 해당 조항에 포함된다고 예측한 성분 중 신규 실험에서 하나 이상의 유해성 함량기준을 충족한다고 예측한 경우를 잠정 '해당'으로 계산했습니다. 이는 **연구용 간소화 규칙**이며 고시의 모든 적용조건을 대체하거나 법적 결론을 확정하지 않습니다. 기존 `covered_by_clause`는 선택한 조항의 적용 여부를 뜻하며 모든 조항을 망라한 규제 지정 여부와 동일하지 않을 수 있습니다.
- **검증셋 분포:** 잠정 정답상 비지정 성분이 포함된 혼합물은 7/30문항이지만, 혼합물 **최종 규제 비해당 정답은 0/30문항**입니다. 따라서 모든 혼합물을 해당이라고 예측하는 기준선의 최종판정 정확도가 100%입니다. 최종판정 정확도를 규제 해당/비해당 *판별력*으로 해석해서는 안 됩니다.
- **정답 신뢰도:** 추가 함량기준 잠정 정답지 75개 성분 중 19개는 포괄 지정, 적용 소번호 또는 제외 조건 등 추가 확인 대상입니다. 독립 법령 전문가 검토는 완료되지 않았습니다. 결론은 **잠정 정답지 일치율**만을 의미합니다.
- **자료 보호:** 450건의 문항별 원본 응답, 사후 연결한 문항별 점수, 75개 성분별 잠정 정답지 및 상세 법령 대조표는 로컬에 보존하며 공개 저장소에는 업로드하지 않습니다. 공개 S7–S9는 집계 결과와 확인 가능한 분석 설정만 담습니다.

## 평가의 정확한 의미

- **검색 성공:** 각 문항 모든 성분의 잠정 Gold에 지정된 정확한 고시 원본 행이 검색 결과에 포함된 경우. 같은 지정번호의 다른 행을 반환하면 인정하지 않습니다.
- **지정범위 정확도:** 성분별 지정범위 포함 여부가 모두 맞고, 혼합물은 고시 제3조의 모든 성분 지정 여부도 맞은 경우입니다. 함량별 준수나 제품 전체 적법성을 판단한 것이 아닙니다.
- **최종 완전정답(strict):** CAS 직접 기재 여부, 지정 관계, 지정범위, 지정번호, 소번호와 혼합물 조건이 모두 정답인 경우입니다. End-to-end는 이에 더해 정답의 정확한 고시 원본 행까지 검색된 경우입니다.
- **S4:** 문항의 모든 성분이 DIRECT_SPECIFIC이면 DIRECT_ONLY, 하나라도 GROUP_INCLUDED/EXPLICIT_EXCEPTION이면 GROUP_OR_EXCEPTION. 이 기준은 연구자의 잠정 Gold에 따른 분석상 범주입니다. 그룹별 난이도·성분 수와 연관되므로 지정방식의 인과효과로 해석할 수 없습니다.
- **일관성(valid_identical_n):** 5번 모두 유효한 JSON 구조의 **성분별 판단과 혼합물 판단**이 동일한 질문 수입니다. 자연어 설명은 제외합니다. Qwen3 4B의 7문항은 5회 모두 같은 형식 오류를 냈으므로 '모두 유효하고 동일' 지표에는 포함하지 않습니다. 모든 반복의 원본 응답이 동일하게 관찰되더라도 정확하다는 뜻은 아닙니다.
- **정확도 SD=0:** temperature=0, 고정 seed=20261120에서 같은 질문에 같은 결과가 재현됐다는 의미입니다. 표본 독립성·다른 프롬프트·다른 생성온도·모델 업데이트까지 검증한 것은 아닙니다.
- **측정 시간:** `task_sec_per_case`에는 검색어 생성 LLM API 시간 + 고시 SQLite 검색 + 최종 판단 LLM API 시간 + 파싱/프롬프트 처리가 포함됩니다. 문항 파일 기록, DB 구축 및 모델 블록 전후 언로드는 제외하며, 각 모델·반복 첫 문항의 로딩 비용은 포함됩니다. `block_wall_sec_total`에는 블록 부대시간도 포함됩니다. 하드웨어 환경은 S6에 기록되어 있습니다.
- **반복 수:** 90문항 × 4모델 × 5회 = 1,800회 평가(검색어 생성/판정 LLM 호출 3,600회). 통계 검정에서는 5회 반복된 동일 질문을 서로 독립인 450문항처럼 취급하지 마십시오.

## 출처 보호·한계

원본 모델 응답 20개 JSONL(문항별 × 5회), 비공개 Gold·법령 근거 감사표, 문항/성분별 오답, `REPEAT_*_PRIVATE.csv`는 공개 저장소에 넣지 않았습니다. 연구자가 로컬에 보존해야 합니다. 원본 질문은 [90문항 입력안](../../expanded_b90/proposals/PROPOSED_90_B_cases.jsonl)에서 확인할 수 있습니다. 실행 코드는 [repeat_b90.py](../../expanded_b90/repeat_b90.py), 설명은 [90문항 실행 안내](../../expanded_b90/README.md)를 참고하세요.

**중요:** Gold는 `CURATED_PROVISIONAL` 상태이고 화학물질 식별·법령 적용에 대한 독립 전문가 검증이 완료되지 않았습니다. 따라서 정확도는 잠정 정답지에 대한 일치율이며, 법적 판단이나 투고용 확정 검증 결과로 간주하면 안 됩니다.
